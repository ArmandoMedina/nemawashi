**En sus palabras.** «El contexto no viaja dentro del agente: se señala en la pantalla de
configuración dónde vive en cada repositorio, y si falta un archivo el programa avisa antes de
abrir el chat, nombrando cuál falta.»

**De dónde salió.** Se le preguntó de dónde saca el contexto el agente conductor cuando el
programa corre contra el repositorio de otro cliente, si no puede traerlo adentro. Contestó que el
contexto se debe parametrizar en la misma pantalla, con avisos si hay archivos que faltan por
ubicar; puso de ejemplo un aviso que diga que no se encontró el documento de producto o el caso de
negocio. Agregó que el aviso se puede omitir para que ya no vuelva a salir, y que así se le da al
usuario la alerta de que va a abrir el chat sin el contexto suficiente.

**Qué queda abierto.** Nada.
