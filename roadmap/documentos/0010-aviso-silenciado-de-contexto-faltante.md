# Falta definir qué hace el programa cuando se silencia el aviso de contexto faltante

> **Esto es lo que se le entrega al experto para que confirme.**

## Lo que entendimos

La regla, tal como quedó: «Falta definir qué hace el programa cuando el usuario silencia el aviso
de contexto faltante y el chat abre a ciegas.»

El caso del que salió: explicando cómo se parametriza el contexto en la pantalla de configuración,
el experto dijo que si falta un archivo el programa avisa nombrándolo, y que ese aviso se puede
omitir para que ya no avise. Dijo que así el usuario entra sabiendo que abre el chat sin contexto
suficiente, pero no dijo qué pasa de ahí en adelante: si el programa lo deja pasar sin más, si
queda marcado en algún lado, o si el agente trabaja distinto sabiendo que le falta contexto. La
vuelta de preguntas autorizada ya se había gastado.

## Donde aplica y donde no

Nada.

## Lo que sigue sin cerrarse

Cuando el usuario silencia el aviso y el chat abre sin contexto suficiente, qué hace el programa:
lo deja pasar sin más, lo deja marcado, o el agente trabaja de otro modo.

## Lo que cambia si esto esta mal

Nada.
